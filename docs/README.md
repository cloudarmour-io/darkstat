# Darkstat Documentation

This directory explains how darkstat works, how the packaging files fit
together, and what changed in this branch.

## Files

- `architecture.md` - how darkstat captures traffic and stores data
- `packaging.md` - how the Debian wrapper and `/etc/default` config work
- `auth.md` - how bind-address-based auth and API-key hashing work
- `changes.md` - summary of the changes made in this branch
